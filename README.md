# 🎬 Movie Search App

A simple movie search app built with **React.js** and the **IMDb/OMDb API**.

## 🚀 Live Demo

👉 [View Live Demo](lucky-malasada-bcd294.netlify.app)

## ✨ Features

* Search movies
* View movie posters
* View movie title and year
* Uses API to get movie data
* Built with React

## 🛠️ Tech Used

* React.js
* JavaScript
* CSS
* API
* `fetch()`
